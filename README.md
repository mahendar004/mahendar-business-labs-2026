# Business Labs Student Registration - Fallback Demo

This is the emergency frontend simulation allowed by the assignment when PHP/MySQL is unavailable.

## Run
Copy this folder into:
C:\xampp\htdocs\business-labs-student-registration

Then open:
http://localhost/business-labs-student-registration/

No MySQL is required.

## Included
Registration, exact duplicate-email message, PDF-only Aadhaar validation, unique stored Aadhaar filename simulation, unified login, role-based dashboards, forgot/reset password, admin filters, admin CRUD, locked Name/Email fields, student profile editing, and localStorage persistence.

This version is for assessment demonstration. It does not upload PDFs to a server because it intentionally operates without a backend.
